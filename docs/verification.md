## 性能实测

基准通过 `cargo run --release -p resona-core --example benchmark -- 1000000` 创建临时合成数据库，使用完整统计而非抽样。

| 数据量 | 概览查询 | 首页面列表 | 说明 |
| --- | --- | --- | --- |
| 10 万轮 | 160–401 ms | 102–179 ms | 优化前基准已达 500 ms 目标 |
| 100 万轮 | 690–740 ms | 150–170 ms | 优化后查询；端到端 UI 耗时另计 |

百万轮整个基准进程峰值 RSS 为 672,694,272 bytes，包含数据库生成等工作；不能理解为常驻应用内存。查询中的紧凑样本约 32 bytes/轮，模型字符串按组驻留。首版尚未实现原方案的 64 MiB 查询硬上限或外部排序。百万轮概览未达到 500 ms，属于已知容量边界。

## 视觉与本机验收

在 500×780 浮层和 1180×850 主窗口下，将实际合成数据截图与批准的五张原型并排比对。已修复列表翻页出屏、详情遮挡筛选、分布散点重叠与图表标注覆盖问题。实际截图明确标记演示数据。

本机 Apple Silicon / macOS 27 已验证真实 Codex/Claude 数据读取、概览、轮次详情、设置保存、登录启动开关往返、浅色/跟随系统主题、采集暂停/恢复及目录选择取消。关闭窗口后进程保留；重复启动重新打开已有窗口，未产生第二个采集进程。历史扫描完成后共有 1,676 个文件，2 个文件含无效源记录并保留异常提示。

## 验证边界

- GitHub CI 已通过 Linux 核心、Apple Silicon 与 Intel 桌面构建以及依赖审计，最终提交状态以 [PR checks](https://github.com/xuzhu-591/resona/actions/workflows/ci.yml) 为准。
- 2026-09-21 用户已通过真实菜单栏点击确认浮层展开和定位修复；本地原生事件与窗口坐标读回也已确认展开/失焦路径。右键菜单、Escape 和多显示器仍未形成完整原生自动验收记录；合成页面结果不代替该边界。
- 最低 macOS 13 的实机安装、Intel 实机运行、多显示器与各类屏幕缩放尚未验证；CI 构建不能替代这些测试。
- 当前本地包为 ad-hoc 签名，未经过 Apple 公证。正式公开 DMG 需要 Developer ID 及公证凭据，发布流程缺凭据时失败，不自动降级。
- 首版只有 schema v1，遇到未来数据库版本会拒绝启动；完整跨 schema 大版本升级尚无实际版本对可测。
